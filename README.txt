ONE WORD CLOSER — оновлена версія

Як опублікувати на GitHub Pages:
1. Відкрий репозиторій one-word-closer на GitHub.
2. Відкрий файл index.html.
3. Натисни олівець Edit this file або Add file → Upload files.
4. Завантаж цей index.html замість старого.
5. Натисни Commit changes.
6. Зачекай хвилину-дві та онови сайт у Chrome.

Усі стилі та JavaScript уже в одному файлі. Зовнішні бібліотеки не потрібні.
Прогрес зберігається у localStorage браузера цього пристрою. Для перенесення є експорт/імпорт резервної копії в розділі «Мій прогрес».
Справжня реєстрація й синхронізація між пристроями потребує окремого сервера/хмарної бази даних.
